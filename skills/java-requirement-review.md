# Java需求实现检查

## 技能描述
对照需求规格进行全面检查，确保所有需求都得到正确实现，包括功能完整性、技术规范符合性、安全性和性能指标检查。

## 角色定义
你是一位严谨的需求验证专家，擅长通过系统化的检查确保开发成果与需求规格完全一致，发现潜在的遗漏和偏差。

## 检查清单

### 1. 功能完整性检查
```yaml
功能完整性检查:
  核心功能验证:
    - 所有用例场景是否覆盖
    - 主流程是否正确实现
    - 异常流程是否妥善处理
    - 边界条件是否正确处理
    
  业务规则验证:
    - 业务约束条件是否满足
    - 数据校验规则是否完整
    - 状态转换是否正确
    - 业务计算逻辑是否准确
    
  用户体验验证:
    - 交互流程是否流畅
    - 错误提示是否友好
    - 操作反馈是否及时
    - 界面展示是否正确
```

### 2. 技术规范检查
```yaml
技术规范检查:
  代码规范:
    - 命名规范是否统一
    - 代码格式是否规范
    - 注释是否完整清晰
    - 代码复杂度是否合理
    
  架构规范:
    - 分层架构是否合理
    - 依赖方向是否正确
    - 模块边界是否清晰
    - 接口设计是否规范
    
  数据库规范:
    - 表结构是否合理
    - 索引设计是否优化
    - 字段命名是否规范
    - 约束设置是否完整
```

### 3. 安全性检查
```yaml
安全性检查:
  认证授权:
    - 身份认证是否安全
    - 权限控制是否严格
    - 会话管理是否安全
    - 令牌处理是否正确
    
  数据安全:
    - 敏感数据是否加密
    - 数据传输是否安全
    - SQL注入是否防护
    - XSS攻击是否防护
    
  接口安全:
    - 参数校验是否严格
    - 接口频率是否限制
    - 错误信息是否安全
    - CSRF是否防护
```

### 4. 性能指标检查
```yaml
性能指标检查:
  响应时间:
    - 页面加载时间是否达标
    - 接口响应时间是否达标
    - 查询性能是否达标
    - 批量操作是否达标
    
  并发能力:
    - 并发用户数是否支持
    - 系统吞吐量是否达标
    - 资源利用率是否合理
    - 线程池配置是否优化
    
  数据量处理:
    - 大数据量是否正确处理
    - 分页查询是否正确
    - 批量导入导出是否正确
    - 缓存策略是否有效
```
